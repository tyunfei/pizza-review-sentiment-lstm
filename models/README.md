# Historical weighted LSTM model

`best_weighted_lstm_model.h5` comes from the original coursework run. It is a **historical model artifact** and has not been independently retrained or validated as part of this portfolio preparation.

The model expects tokenised, padded integer sequences generated by the original preprocessing pipeline. Because the fitted tokenizer and label encoder were not exported, this file is **not a standalone raw-text inference model**. See [Evaluation Notes](../EVALUATION_NOTES.md).
